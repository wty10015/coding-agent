# v0.1.0 候选发布说明

状态：准备中。本文随发布准备提交写入，**不表示** `v0.1.0` tag 或 GitHub Release 已经创建。

## 定位

v0.1.0 是一个可安装的本地 Alpha 快照，面向公开、可验证的基础模块。它适合学习和验证受限工作区检查、应用层变更策略、本地状态结构及独立控制流；不应被视为已经接入真实模型的完整 Coding Agent。

## 安装与检查

需要 Python 3.10 或更新版本：

```text
python -m pip install -e ".[dev]"
python -m pico --help
python scripts/check_quality.py
python -m pico.public_evaluation --check --output docs/evaluation/readonly-workspace-v1.json
```

公开的质量门禁会在 Python 3.10、3.11、3.12 上安装项目，执行已跟踪测试、Ruff、评测证据复现和 CLI help。

## 公开验证范围

- `pico` CLI 可展示帮助、选择 Provider 配置，并执行只读工作区检查。
- `readonly_workspace` 对合成输入的文件可见性、读取、搜索和越界拒绝有回归证据。
- `guarded_workspace`、持久化、checkpoint、分层记忆和 `bounded_loop` 作为独立模块存在相应单元测试。
- `mini-pico` 是不连接网络或真实 Provider 的教学示例。

## 已知限制

- 公开树没有集成式 runtime，也没有真实 Provider 客户端调用；Provider 配置入口不是 API 调用承诺。
- approval policy、路径检查和命令拦截是应用层措施，不提供 OS 级沙箱或隔离。
- 评测是确定性的合成离线回归，不代表真实模型质量、Provider 兼容性、性能、成本、延迟或端到端 Agent 表现。
- 公共接口、命令参数和本地存储格式仍可能在后续 Alpha 版本中调整。

## 发布门禁

创建 annotated `v0.1.0` tag 和 GitHub Release 前，必须同时满足：

1. `origin/main` 指向本次发布准备提交。
2. 该提交的 Python 3.10、3.11、3.12 CI 均成功。
3. 安装、已跟踪测试、Ruff、评测复现和 CLI help 均由 CI 完成。
4. GitHub CLI 已重新认证，并确认没有同名 tag 或 Release。
