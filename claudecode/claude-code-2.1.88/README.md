# Coding Agent Runtime

我在这里维护项目使用的打包运行文件。项目整体目标、当前修缮状态和开发方式见仓库根目录的 README。

## 运行环境

随包元数据要求 Node.js 18 或更高版本。可在本目录运行以下命令查看 CLI 帮助：

```sh
node cli.js --help
```

## 本地凭证

需要访问模型服务时，请在本机配置所需凭证。不要将 API 密钥或个人配置提交到仓库。

## 隐私与数据

运行期间的网络请求和数据处理取决于所配置的模型服务。使用前请阅读相应服务的隐私与数据使用条款。

## 许可

我保留随包提供的版权和许可文件；具体条款以本目录中的许可文件为准。
